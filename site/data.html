数え方

  • 見出し・title・一覧・トップ・ブランドの「安全靴・プロスニーカー」の数は、先芯ありの型番（先芯欄の表記が樹脂系・鋼製・先芯あり〈材質はメーカー未記載〉）で数えます。先芯欄が空でも、JSAA型式認定の一覧と照合できた型番と、規格欄に JSAA A種・B種・JIS T8101 の表記がある型番は先芯ありに数えます（下の「先芯・締め方・カット・幅」の先芯の規則）。先芯なし・先芯の記載なしの型番は含めません

  • 一覧の中は「先芯あり」「先芯なしの作業靴」「先芯の記載なし」の節に分けます。条件で探すの件数は、表示の範囲（既定は公式に掲載ありで先芯ありだけ）を件数の横に書きます
  • JIS T8101 と JSAA の型番が1つも無いブランドは、総称「安全靴・プロスニーカー」ではなくメーカーの呼び方（セーフティシューズ・作業靴）で書きます

規格の扱い

規格（JIS T8101・JIS T8103・JSAA認定）は、メーカーの製品ページ・カタログ、または日本保安用品協会（JSAA）の型式認定合格製品一覧に明記がある型番だけを表示しています。「規格の記載なし」は当サイトが明記を見つけられなかったことを示し、規格外であることを意味しません。

  • 規格欄が空、または「該当なし」「未記載」で始まる → 規格の記載なし
  • 規格欄を読点「、」で区切り、区切りごとに判定する（全角半角・空白の違いは無視）
  • 「T8101」を含み、同じ区切りに「相当」「準拠」が無い → JIS T8101
  • 「T8103」を含み、同じ区切りに「相当」「準拠」が無い → JIS T8103
  • 「JSAA」を含み「A種」がある → JSAA A種／「B種」がある → JSAA B種／どちらも無い → JSAA（種別の表記なし）
  • 上のどれにも当たらない区切り（EN ISO・JIS T8108・「相当」「準拠」の表記など） → その他の表記。ただし「RoHS」「グリーン購入法」「エコマーク」「IEC」で始まる区切りは規格の区分に入れません（環境などの表記のため）
  • 1つの型番が複数に当たる場合は、当たったすべてに載せる

JIS の作業区分（S種・L種など）の読み取りは、絞り込みには使っていません（記号の読み方はJISの記号の読み方）。

JSAA 認定番号の紐付け

  • メーカーの製品ページ・カタログに認定番号の記載がある型番は、その番号を表示します（メーカー表記の引用。値の出どころがカタログの紙面なら「メーカーのカタログに記載の認定番号」と書きます）
  • JSAA の一覧の品番欄の1件ごとに、色番・色名を除いた「基底品番」を作ります：「#」以降（色番号と色名）を外す／品番の後ろに空白で続く色名だけの語（ブラック・ホワイト・ネイビー・黒・白 など色の語だけでできた語）を外す／ミズノの10桁の品番（例 F1GA190709）は末尾2桁の色番号を外す（F1GA1907）。色名でない語（静電・甲プロ・フード など）は外しません
  • 基底品番が、当サイトの型番の公式品番と完全に一致したときだけ紐付けます（全角半角・空白・®の違いだけは無視）。アシックスの公式品番は製品ページの品番（例 1271A029-602）の色番号の前まで（1271A029）
  • 品番が一致しても、一覧の品名の系統（アシックスの CP 番号、ミズノ オールマイティの系統名）が当サイトの型番と食い違う行は紐付けません（一覧の品番欄の誤記とみなす。例：品名「LADY WINJOB CP207」の行の品番が CP205 の品番と一致しても CP205 には紐付けない）
  • 有効期限が一覧の版日より前の認定は、規格の区分（JSAA A種 など）の判定には使わず、「JSAA 一覧の記載」として認定番号と有効期限を示すだけにします
  • 有効期限が一覧の版日より後でも、当サイトの最終確認日より前の日付の認定は、区分の判定には使ったまま、型番の要点・比較表・JSAA型式認定の一覧のページに有効期限の日付を添えます（更新の有無は一覧からは分かりません）
  • 部分一致・前方一致・名前の似ている型番では紐付けません

型番のページの単位

  • アシックス ウィンジョブは、型番の CP 番号（CP209・CP20E など）が同じ型番の表記を1つのページにまとめ、版・色（BOA RR2・MARBLE・LC など）の違いはページ内の「版・カラーの表」に行として示します
  • 仕様の列（規格・先芯・ソール性能・締め方・カット・幅・重量の表記・サイズ範囲・価格）と素材の表記が同じで、製品名の違いがその型番の色の表記の語だけの型番は、色違いとして1つのページにまとめます（色の表記が空の型番はまとめません）
  • 仕様の列と素材の表記がすべて同じで、製品名の違いが色の語・品番だけの型番（例：New Balance Boston BS-118／BS-218、スプリント2.1 オリーブ／ブラック＆ホワイト、SL11-BL／SL11-R）も1つのページにまとめます。製品名が品番だけ・ブランド名と品番だけ・「セーフティスニーカー」などの一般名と品番だけの型番は、同じ製品である手がかりが無いのでまとめません
  • サイトの「型番数」はページの数です（まとめた版・色は1型番として数えます）

先芯・締め方・カット・幅の区分

先芯

  • 「先芯なし」「先芯無し」「使用していません」「なし」「無」 → 先芯なし（最初に判定）
  • 「鋼」「スチール」を含む → 鋼製の先芯
  • 「樹脂」「グラスファイバー」「ガラス繊維」「ACM」「プラスチック」を含む → 樹脂系の先芯
  • 先芯についてのサイズの但し書き（「（30cmは鋼製先芯）」「※サイズ30.0cmは鋼製先芯になります。」など）は区分の判定に使いません（表記はそのまま出します）
  • 「先芯」の語があり、材質の語も否定の語も無い（「先芯入り」「軽量先芯入り」「先芯：先芯形状を…」など） → 先芯あり（材質はメーカー未記載）
  • 先芯欄が空でも、日本保安用品協会の型式認定の一覧と照合できた型番と、規格欄に JSAA A種・JSAA B種・JIS T8101 の表記がある型番 → 先芯あり（材質はメーカー未記載）。JSAA の規格（プロテクティブスニーカー）と JIS T8101（安全靴）は、どちらもつま先を先芯で防護することを定めているためです。JIS T8103（静電気帯電防止靴）には先芯なしの区分（W）があるので、JIS T8103 の表記だけでは数えません。先芯欄に「先芯なし」と書かれた型番はそのまま先芯なし
  • 上のどれにも当たらない説明文（「甲プロテクタ付」など） → 表記から読み取れず

先芯欄に製品の説明文がまとめて入っている型番は、先芯の表記だけを切り出して表示します。先芯の種類・材質の語が無い説明文は「—（メーカー未記載）」と表示し、出典ページの記載を下に添えます。

締め方

  • 締め方欄の表記に「BOA」を含む → BOA
  • 「ダイヤル」を含み「BOA」を含まない → BOA以外のダイヤル（表記はメーカーのまま。例：DISCレーシングシステム（ダイヤル））
  • 「ベルト」「マジック」「面ファスナー」を含む → ベルト・面ファスナー（表記はメーカーのまま。アシックスの公式表記は「ベルト」）
  • 「ファスナー」（「面ファスナー」を除く）「ジッパー」「ジップ」を含む → ファスナー
  • 「スリッポン」「スリップオン」を含む → スリッポン
  • 「紐」「ひも」を含む → 紐（「紐なし」「ひもなし」は除く）
  • 上のどれにも当たらない表記 → その他の表記。複数に当たる表記は、当たったすべてに載せる（例：「ベルト付きスリッポン」はベルト・面ファスナーとスリッポン）

カット

  • カット欄の表記が「ロー」「ミドル（ミッド）」「ハイ」で始まる型番をそれぞれに分けます（「ハイ（半長靴）」はハイカット）
  • 長靴・半長靴・ブーツの一覧は、製品名・カットの表記・メーカーの公式分類に「長靴」「半長靴」「長編上」「中編上」「ブーツ」の語がある型番

幅

  • 幅の表記を「／」で区切り、「2E」「EE」→2E、「3E」「EEE」→3E、「4E」「EEEE」→4E（「相当」「方向け」の表記も同じ区分に数え、表示はメーカー表記のまま）
  • 「EE／EEE」のように併記の型番は両方に載せる

JIS の記号の読み方

  • 規格欄の JIS の記号は位置で読みます：「T8101」の直後（T8103 だけのときは「T8103」の直後の括弧の後ろ）から、読点「、」「,」・中黒「・」・「合格」・「JIS」・開き括弧の手前までを「/」で区切ります
  • 1番目は材料区分（CⅠ・CⅡ・「〜製」）、2番目は作業区分（U・H・S・L）。どちらかがこの形でない表記は「記号を読み取れない表記」として記号では数えません（作業区分だけは「S種」などの語から読みます）
  • 3番目以降が付加的性能とカテゴリーです：P＝耐踏抜き性／P1＝かかと部の衝撃エネルギー吸収性・表底の耐燃料油性・クリート付き表底（耐踏抜き性は含みません）／P2＝P1＋耐踏抜き性／P3＝P2＋表底の耐高熱接触性／P4＝P1 と同じ3性能（クラスⅡ）／P5＝P4＋耐踏抜き性／E＝かかと部の衝撃エネルギー吸収性／F1・F2＝耐滑性／W＝耐水性／H＝表底の耐高熱接触性（2番目の H は重作業用の作業区分）／HI1・HI2＝靴底の高温熱伝導性／CI1・CI2＝靴底の低温熱伝導性／BO・UO＝表底・甲被の耐燃料油性／M＝足甲プロテクタ／C＝耐切創性／I-600 など＝電気絶縁
  • JIS T8103 の括弧の中（ED-P／C2 など）は静電靴の区分と環境区分で、付加的性能には数えません（ED-W の W も耐水ではありません）
  • 「相当」「準拠」がある区切りは、記号も語も読みません。製品名の「P-4」などは記号として読みません（記号を読むのは規格欄だけ）

防水の一覧は、型番・製品名・ソール性能の表記に「防水」「G-TX」「GORE-TEX」「ゴアテックス」の語がある型番です。

重量の扱い

重量はメーカーの表記を片足あたりに揃え、測定条件（サイズ・片足／両足）を併記しています。メーカーごとに測定条件が異なるため、数値の単純な比較には注意してください。片足・両足の別が表記に無い型番、「／足」「1足」の表記の型番、重量の数値と表記の数値が合わない型番は、片足の値を出さずメーカーの表記のまま載せています。

  • 片足の表記：メーカー表記に「片足」「片方」があり、データベースの重量の数値が表記の数値と一致する（228件）
  • 両足の表記を2で割った値：メーカー表記が「両足」で、データベースの重量の数値×2 が表記の数値と合う（差2g以内）。片足の値は表記の数値を2で割った値（端数は切り捨てない）（98件）
  • 「／足」「1足」の表記：メーカー表記が「780g／足」「（26.0cm 1足）」の形。「足」は靴を数える単位で左右1組を指すため、当サイトは片足の値を出さない（355件）
  • 片足・両足の別の記載なし：メーカー表記に片足・両足・足の別が無い（例「約410g(26.5cm)」）。片足の値を出さない（63件）
  • 表記のみ（数値の記録なし）：メーカー表記はあるが、データベースに重量の数値の記録がない。表記だけを出す（0件）
  • 表記と換算値が一致しない：データベースの重量の数値が表記の数値と合わない。片足の値の表示を保留（0件）
  • 重量の記載なし：—（71件）

片足・両足の基準は、メーカーの公式の資料（製品ページ・カタログの凡例や注記）に明記がある型番だけ換算します。明記が無いブランドの「／足」「1足」の表記は換算しません。

メーカーの表記に「約」があれば、片足の値にも「約」を付けます（両足の表記を2で割った値も同じ。例：片足 約375g）。許容差の「±」は、片足の表記の型番だけ表記のとおり添えます（例：片足 460±10g）。両足の表記を2で割った値には「±」を付けません（許容差を2で割りません）。各型番のページの「メーカー表記」は、表記から重さの部分（「約」「±」の幅・測定条件の括弧を含む）を切り出したものです。前後のラベル・色番号は外し、全角の「ｇ」「㎝」は「g」「cm」にそろえています。

サイズ範囲・発売の表記

サイズ範囲はメーカー表記の最小〜最大です。途中のサイズが無い型番があるため、出典のサイズ表記を各型番のページに併記しています。

発売は、メーカーが公式ページの画面に出している表記だけを載せます（ミズノは公式オンラインショップの仕様表の「発売シーズン」）。画面に出ていない発売日は使いません。

シリーズの分け方

  • ミズノ：製品名の「オールマイティ」の後ろの2文字と数字の表記（LSII・LSIII・TDII・HWII・VH など。「LSll」「LS II」は LSII にそろえる）
  • プーマセーフティ：製品名の先頭のカタカナの語と版の数字（ライダー2.0・2.1 はライダー2）
  • ニューバランス（ドンケル）：シリーズ欄（Portland・NewYork・Boston・Harrisburg・Portsmouth）
  • 丸五：製品名に「マンダム」「mandom」がある型番
  • 3型番以上あり、シリーズ名の検索語がある組だけ一覧ページにします

ランキングの数え方

  • ランキング（総合と、溶接・建設・鳶・屋根・工場・物流・倉庫・運送）は、公式に掲載ありの先芯ありの型番を、数える条件の表記がある数の多い順に並べます。条件の表記が1つも無い型番は載せません（その性能が無いという意味ではありません）
  • 同数なら型番名の検索数（キーワード調査ツール aramakijake の月間の値・2026-09-19〜20 取得。型番の語〈英字1〜5文字＋数字2〜5桁・4文字以上〉の前後が英数字でない語だけ。版・色をまとめた型番のページは、まとめた型番の語の検索数を合わせる）、それも同じならブランドの検索数（ブランドの並びと同じ）の多い順。それも同じなら同順位です
  • 靴の形（製品名・カット欄・メーカーの公式分類に「長靴」「半長靴」「ブーツ」の語があれば長靴・半長靴・ブーツ型、それ以外は短靴・スニーカー型）ごとに順位を付けます。総合の短靴・スニーカー型は規格の部（JIS の安全靴・静電靴／JSAA のプロスニーカー／規格の記載なし・その他）、工場は作業区分（U・H・S・L・JSAA A種・B種）ごと
  • メーカーが公式分類・製品名・説明に「消防」と書いている型番は、形の節とは別の「消防向けの記載もある型番」の節で順位を付けます
  • 総合と工場は、性能の11項目（耐滑・静電気帯電防止・耐燃料油／耐油・耐踏抜き・かかと部の衝撃吸収・耐水／防水・高温・足甲の保護・電気絶縁・耐切創・低温）のうち表記がある数。1つの項目は、根拠（JIS の記号・JSAA の付加的性能・メーカーの語）がいくつあっても1と数えます。先芯・作業区分・メーカー独自の語（グリップ性など）は数えません
  • JSAA の付加的性能は耐滑性・かかと部の衝撃エネルギー吸収性・静電気帯電防止性・耐踏抜き性の4つだけで、耐燃料油・高温・耐水はありません。そのため JSAA の型番は、これらの記号の条件には入りません（規格の部を分けているのはこのためです）
  • 順位は表記の数の順で、安全性・作業への適否・品質の順位ではありません。メーカー公表値による比較で、実機での装着検証はしていません。報酬（広告）の有無で順位を変えていません。順位はビルドのたびに計算し直します

並べ替えの計算式（条件で探す）

並び順は次の計算だけで決めます。広告（アフィリエイト）の有無・報酬で順位を変えません。人気順・評価順は置いていません（そのデータを持っていません）。

  • ブランドの並びは検索需要の順です：キーワード調査（aramakijake の月間の値・2026-09-19〜20 取得）の「ブランド名＋安全靴」の2語の検索語（語順2つ・カタカナと英字の表記）の月間検索数の合計が多い順
  • 「安全靴」単独と同じ数（135,000）の語は辞書の衝突の疑いがあるため数えません（アシックス 安全靴）。検索数の無いブランドは、公式に掲載ありで先芯ありの型番の多い順
  • ブランドの中の並びは型番の文字の順です。報酬（広告）の有無や、仕様の充実度では並べません
  • ブランド順（条件を選んでいないときの既定）：上のブランドの並び → ブランドの中は型番の文字順（数字は数として比較）。一覧・ブランドの一覧・トップのブランドも同じ並び
  • 一致数順（条件を選んだときの既定）：選んだ条件のうち「一致」の数が多い順。同数ならブランド順
  • 片足重量が小さい順：片足の値がある型番だけを小さい順に並べます（片足の値が無い型番はこの並びでは表示しません）
  • 価格が安い順（区分ごと）：税込の区分 → 税別の区分 → オープン価格 → 記載なしの順に、区分の中で金額の安い順
  • 最小サイズが小さい順：サイズ範囲の最小の小さい順（同じなら最大の大きい順）
  • 型番順：型番の文字順
  • 表示の範囲の既定は、公式に掲載ありで先芯ありの型番だけです（先芯なしの作業靴・先芯の記載なしの型番は「表示の範囲」で含められます）
  • 条件に「一致しない」型番は表示しません。「メーカー未記載」の型番は既定では表示せず、件数を示して表示に切り替えられます

「メーカー未記載」の定義

「—（メーカー未記載）」は、メーカーの公式ページ・カタログを確認したうえでその項目の記載が見つからなかったことを示します（推測では埋めていません）。

メーカーの記載が無い項目の表示は「—（メーカー未記載）」の1種類です。規格は、メーカー表記も JSAA の一覧の紐付けも無いときに「規格の記載なし（確認日）」と書きます。比較表の「JSAA認定番号」の行は、メーカー表記にも JSAA の一覧にも無いとき「—（メーカー表記・JSAA 一覧のどちらにも記載なし）」、JSAA型式認定の一覧の表は、協会の一覧の欄が空欄のとき「—（品番欄は空欄）」のようにその欄の名前で書きます。
